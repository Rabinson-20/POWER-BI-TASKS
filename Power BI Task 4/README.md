# Power BI Task 4 - Dashboard

## 📊 Project Overview

This project focuses on developing an interactive Power BI dashboard to explore and understand the given dataset. The dashboard uses different visual elements, KPI indicators, slicers, and filters to present important information in a simple and effective manner.

## 🎯 Objectives

* Load and prepare the dataset for dashboard creation.
* Perform data cleaning and transformation using Power Query.
* Create useful measures and calculations using DAX.
* Represent data using suitable charts and visualizations.
* Add interactive slicers and filters for detailed analysis.
* Identify important trends, comparisons, and performance indicators.

## 🛠️ Tools & Technologies

* Microsoft Power BI Desktop
* Power Query
* DAX
* Data Modeling
* Interactive Data Visualization

## 🔄 Project Steps

### Step 1: Import the Dataset

* Open Power BI Desktop.
* Select **Get Data**.
* Choose the required data source.
* Import the dataset into Power BI.
* Check whether all required columns and records are available.

### Step 2: Open Power Query

* Select **Transform Data**.
* Open the dataset in Power Query Editor.
* Review the imported data before creating the dashboard.

### Step 3: Clean and Transform the Data

* Check the data types of each column.
* Change incorrect data types where required.
* Remove unnecessary columns or data.
* Check for blank or missing values.
* Clean inconsistent values.
* Format the columns appropriately.

### Step 4: Apply the Changes

* After completing the required transformations, select **Close & Apply**.
* The cleaned data is then loaded into Power BI for analysis.

### Step 5: Create Data Relationships

* Open the **Model** view.
* Check the available tables and their relationships.
* Create relationships between related tables when required.
* Verify that the relationships work correctly for analysis.

### Step 6: Create DAX Measures

* Go to the **Modeling** section.
* Create the required measures using DAX.
* Use these measures for calculating important metrics.
* Add the measures to KPI cards and other visuals.

### Step 7: Create KPI Cards

* Add Card visuals to the report.
* Select the required measures.
* Display important summary values such as sales, profit, averages, or other relevant metrics.
* Format the cards for better readability.

### Step 8: Create Charts

Create suitable visualizations based on the data:

* Use **Bar/Column Charts** for comparisons.
* Use **Line Charts** for time-based trends.
* Use **Tables/Matrix** for detailed information.
* Select appropriate fields for the X-axis, Y-axis, values, and categories.

### Step 9: Add Slicers

* Add slicer visuals to the dashboard.
* Add fields such as date, category, region, or other relevant fields.
* Allow users to select specific values.
* Check that the slicers interact correctly with the dashboard visuals.

### Step 10: Format the Dashboard

* Arrange the visuals properly.
* Add suitable titles.
* Adjust font sizes and visual formatting.
* Align the charts and KPI cards.
* Make the dashboard clean and easy to understand.

### Step 11: Add Visual Interactions

* Select the required visual.
* Check how it affects other charts.
* Configure visual interactions where necessary.
* Test the slicers and charts together.

### Step 12: Analyze the Dashboard

* Use different slicer selections.
* Compare categories and groups.
* Check trends over different time periods.
* Observe the KPI values.
* Identify important patterns and variations in the data.

### Step 13: Save the Project

* Save the Power BI report as:

  `PowerBITask4.pbix`

* Keep the README file along with the project for documentation.
